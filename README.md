RL Stats - Rocket League Tracker

INSTALLATION
1. Install [Millennium](https://github.com/SteamClientHomebrew/Millennium) for Steam.
2. Copy RL Stats.star into "Program Files (x86)\Steam\millennium\plugins" Millennium's plugins folder.
3. Enable "Rocket League Tracker" in Millennium Settings and reload Steam if needed.

The plugin adds an "RL Stats" button to Steam Community profile pages.
